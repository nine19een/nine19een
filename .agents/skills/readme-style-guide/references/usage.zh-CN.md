# 简单用法

这个 Skill 只管 README 的表达、组织、翻译与格式，不负责核验功能，也不会自己找项目、扫源码或运行产品。准备一段已确认事实、现有文档，以及允许编辑的位置即可，不需要填写复杂表单。

例如，可以这样调用：

```text
使用 $readme-style-guide，把下面的已确认材料整理成同目录的
README.md 和 README.zh-CN.md。保持简短，只改这两份文档。
这是表达任务，不读取源码，不联网，不执行产品命令。

以下内容均为虚构练习材料：
名称：Pocket Pebble。
用途：把本地纯文本笔记按日期排列并导出文本索引。
运行要求：Python 3.12，在终端使用。
已确认命令：python pebble.py notes/
输入：用户指定的本地 notes/ 目录。
输出：当前目录的 index.txt；再次运行会覆盖此文件。
验证状态：命令仅有文档记录，本次没有执行。
许可：未提供。
截图和在线演示：未提供。
```

可以另加“用轻松口吻”“这是资料索引，导航优先”或“沿用现有章节”等风格要求。风格可以变，事实、费用、限制和许可不能随之扩大。

材料缺少命令、许可或演示时，Skill 会先完成已知部分，并在交付说明里单独指出缺项；正式 README 中不放猜测、占位链接或 TODO。提供的命令即使被写进代码块，也不代表运行成功。

产物默认是英文 `README.md` 与简体中文 `README.zh-CN.md`，首行使用“中文 / ENG”的真实相对导航。格式检查仅检查路径、围栏与导航等机械事项，不等于事实、翻译或功能验证。

如需测试 Skill 在新会话中的行为，可以单独取用 [A–F 虚构输入](../evals/input-cases.md)。这些是输入材料，不含预期答案；提供它们不代表已经执行测试、安装 Skill 或完成自动发现验证。
